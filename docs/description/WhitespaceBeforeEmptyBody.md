<div>

Checks that a whitespace is present before the opening brace of an empty
body.

</div>

This check applies to the following tokens: Methods and constructors,
Classes, interfaces, enums, and records, Annotation definitions, Loops:
`while`, `for`, `do-while`, Lambdas and anonymous classes, Static
initializer blocks, Try-catch-finally statements, Synchronized blocks,
Switch statements.

A body containing only comments is considered empty by this check.
